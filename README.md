## Overview

Mini Golf is a small 3D environment designed and assembled in Unity. The course combines a striped fairway with a pond, lily pads, rocks, a windmill, START and FINISH signs, trees, bushes, and flowers.

The scene was built using Unity's primitive Cubes, Spheres, and Cylinders. Position, Rotation, and Scale were used to arrange the objects, while custom materials bring colour and visual consistency to the environment.

## What I Learned

This project helped me understand how a well-organised Hierarchy makes a Unity scene easier to manage. I also learned how small changes in the scale and rotation of duplicated objects can make a scene feel more natural. Finally, adjusting the camera angle, materials, and lighting helped me present the environment more clearly.

## Open the Project

1. Download or clone the repository.
2. Open Unity Hub and choose **Add project from disk**.
3. Select the project folder.
4. Open the project with a compatible Unity version.
5. Open the Mini Golf scene from the `Assets` folder.
